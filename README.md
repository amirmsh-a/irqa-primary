# الزيارات الصفية — أداة معارف للملاحظة الصفية

موقع عربي (RTL) لإدارة زيارات الملاحظة الصفية للمعلمين، بديلاً عن مصنف Excel.
التقنيات: React + TypeScript + Tailwind CSS + Supabase (قاعدة بيانات PostgreSQL ومصادقة).

## التشغيل السريع (نسخة تجريبية محلية بدون خادم)

```bash
npm install
npm run dev
```

افتح الرابط الذي يظهر (غالباً http://localhost:5173). ما دام ملف `.env` غير موجود يعمل الموقع
بنسخة محلية تحفظ البيانات في المتصفح فقط، وهي مناسبة للتجربة لا للاستخدام الفعلي.

## الربط بقاعدة بيانات Supabase (للاستخدام الفعلي)

1. أنشئ مشروعاً جديداً في https://supabase.com
2. من **SQL Editor** شغّل الملفين بالترتيب:
   - `supabase/01_schema.sql` — الجداول والصلاحيات (RLS) والدوال
   - `supabase/02_seed.sql` — البيانات الأولية: المدرسة، 12 مادة، 32 صفاً، 20 معياراً، 60 معلماً
3. من **Authentication → Sign In / Providers → Email** عطّل خيار **Confirm email**
   (حتى تعمل حسابات المعلمين والملاحظين فور إنشائها). إن أبقيته مفعّلاً فعلى كل مستخدم
   فتح رسالة التأكيد قبل أول دخول.
4. انسخ `.env.example` إلى `.env` وضع فيه القيم من **Project Settings → API**:
   ```
   VITE_SUPABASE_URL=https://xxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=...
   ```
5. شغّل `npm run dev`، وافتح الموقع: ستظهر صفحة **إنشاء حساب مدير النظام**.
   أول حساب يُنشأ يصبح مدير النظام، فأنشئه مباشرة بعد تجهيز القاعدة.
6. من **الإعدادات → المستخدمون** أضف الملاحظين وحسابات المعلمين (كل حساب معلم يُربط باسمه في القائمة).

### النشر على الإنترنت

```bash
npm run build      # ينتج مجلد dist
```

ارفع مجلد `dist` إلى أي استضافة ثابتة (Vercel، Netlify، Cloudflare Pages…)، وأضف المتغيرين
`VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` في إعدادات الاستضافة قبل البناء.

## الصلاحيات

| الدور | ما يستطيعه |
|---|---|
| مدير النظام (admin) | كل شيء: الزيارات، الخطة، الإعدادات، المعايير والأوزان، المستخدمون |
| ملاحظ (observer) | تسجيل الزيارات وتعديلها، الخطة، الاستيراد والتصدير |
| معلم (teacher) | يرى زياراته فقط ويكتب «تأملات المعلم»؛ لا يعدّل الدرجات |

الصلاحيات مفروضة في قاعدة البيانات نفسها (Row Level Security)، لا في الواجهة فقط.

## قواعد الحساب

- الوزن النسبي للمعيار = الدرجة المستحقة × الوزن.
- الحدود العليا: الإدارة الصفية 20 / 32، الممارسات التدريسية 40 / 44، الملاحظة والتغذية الراجعة 20 / 24.
- الإجمالي من 80، والنسبة الموزونة من 100 (مجموع الأوزان 25 × 4).
- يُحفظ الوزن مع كل درجة (`visit_scores.weight`)، فتعديل الأوزان لاحقاً لا يغيّر نتائج الزيارات السابقة.
- لا يُسجَّل رقم الزيارة نفسه مرتين للمعلم نفسه (قيد فريد في قاعدة البيانات).

## الاستيراد من Excel

من صفحة **الاستيراد والتصدير** اختر المصنف الحالي (xlsx أو xlsm). تُقرأ ورقة `Evaluation`
بأعمدتها كما هي، وتظهر معاينة قبل الحفظ. ملف التصدير يستخدم التخطيط نفسه ويمكن إعادة استيراده.

## هيكل المشروع

```
supabase/01_schema.sql   الجداول + RLS + الدوال (save_visit, set_teacher_reflection)
supabase/02_seed.sql     البيانات الأولية (يولَّد من src/lib/seed-data.json عبر scripts/gen-seed.mjs)
src/data/                طبقة البيانات: supabaseApi.ts و localApi.ts بواجهة واحدة (api.ts)
src/lib/                 الحسابات (calc.ts)، Excel (xlsx.ts, evaluation.ts)، التواريخ والهجري (util.ts)
src/pages/               الصفحات
src/components/          الواجهة المشتركة وتقرير A4 (ReportSheet.tsx)
```
